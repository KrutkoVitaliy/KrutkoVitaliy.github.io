Request account or data deletion

Stellar Abyss: Idle Orbit · Vitalii Krutko · October 19, 2026

You can request deletion without installing or reopening the game.

Send a request

Email vitaliiinm@gmail.com with the subject Stellar Abyss account or data deletion.

  1. Say whether you want to delete this game's cloud account and saves, request deletion of analytics or advertising data, or both.
  2. Include your game Player ID if you already have it. Otherwise describe the account you used and provide a contact address so we can arrange ownership verification. You can submit the request without a Player ID and without reinstalling the app.
  3. We will reply about the verification needed and the status of the request. Do not send passwords, authentication tokens, recovery codes, or payment details.

What deletion covers

For builds with voluntary Unity sign-in enabled, deleting the game cloud account removes its saved progress slots from Unity Cloud Save and its Unity Authentication identity for Stellar Abyss. Your global Unity Player account and accounts in other games are separate. Signing out alone does not delete cloud data.

Cloud account deletion does not erase local progress or backups on devices. Cloud saves are not merged with local progress, and deletion of cloud data cannot be undone through the game.

Analytics and advertising data requests are handled for the relevant service and identifiers after ownership verification. Tell us if these are part of your request. Service backups, security records and any legally required retention follow Unity's policies; we will explain applicable retention when responding. See the privacy policy and Unity's game player privacy policy.

From the game

In a build where cloud sign-in is available, you can also sign in and open Settings → Cloud Save → Delete cloud account, then confirm. This action deletes this game's cloud saves and game account; it does not delete your global Unity account.

Earlier store builds may not have a cloud account. You can still use the email route above for questions or data requests about those builds. Their data handling is described in the archived policy.
