Progress and changes

Game progress is saved locally on the device. In builds with Unity Cloud Save enabled, optional Unity sign-in allows you to manually save and load progress. Cloud slots from different devices are separate. Loading replaces local progress after confirmation, keeps a local backup, and does not merge later progress.
